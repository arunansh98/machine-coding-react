# Quotes Fetcher App

A simple React application that fetches random quotes from the [Quotable API](https://github.com/lukePeavey/quotable) and displays them on the page. Users can click a button to load additional quotes.

## Features

- **Random Quote Fetching:** Retrieves a random quote from the Quotable API when the app loads.
- **Load More:** Users can click the "Load More Quotes" button to fetch and display additional quotes.
- **Loading State:** Displays a loading indicator while the application fetches data.


## Future Enhancements

- **Improved Error Handling:** Add more robust error handling for API failures.
- **Pagination/Infinite Scroll:** Implement pagination or infinite scrolling to continuously load quotes.
- **Responsive Design:** Enhance the UI to be more responsive on various screen sizes.
